Here are the comprehensive implementation instructions for building the Dendritic Heterogeneity Spiking Recurrent Neural Network (DH-SRNN) to replicate the SSC dataset heatmap results from Figure 5f. 

These instructions extract the exact mathematical formulations, network topologies, and hyperparameters directly from the study so you can construct the model from scratch.

### **1. Core DH-LIF Neuron Dynamics**
[cite_start]The DH-LIF neuron incorporates multiple dendritic branches, each maintaining its own continuous current state, which collectively drives the soma's membrane potential[cite: 1268, 1284].

**Parameters to Initialize per Layer:**
* [cite_start]**$\hat{\alpha}_d$**: Learnable pre-sigmoid timing factors for $D$ dendritic branches[cite: 1288, 1450].
* [cite_start]**$\hat{\beta}$**: Learnable pre-sigmoid timing factor for the soma membrane potential[cite: 1288, 1450]. [cite_start]Initialize these following a "medium" or "large" normal distribution[cite: 893, 894].
* [cite_start]**$u_{th}$**: The firing threshold[cite: 1284].
* Apply a sigmoid clamp during the forward pass to restrict timing factors between $(0, 1)$:
    [cite_start]$$\alpha_d = \text{sigmoid}(\hat{\alpha}_d), \quad \beta = \text{sigmoid}(\hat{\beta})$$ [cite: 1288]

**Timestep Updates ($t$):**
For each branch $d \in \{0, 1, \dots, D-1\}$, calculate the total synaptic input combining feedforward ($X$) and recurrent ($O$) inputs:
[cite_start]$$I_d^{t} = W_d X^{t} + U_d O^{t-1}$$ [cite: 1291]
Update the dendritic memory current:
[cite_start]$$i_d^{t} = \alpha_d i_d^{t-1} + (1-\alpha_d) I_d^{t}$$ [cite: 1302]
Integrate the dendritic currents into the soma and apply a soft reset mechanism (subtracting $u_{th}$ if a spike occurred at the previous timestep):
[cite_start]$$u^{t} = \beta u^{t-1} + (1-\beta) \sum_{d=0}^{D-1} i_d^{t} - O^{t-1} u_{th}$$ [cite: 1295, 1459]
Generate the output spike using the Heaviside step function $H(\cdot)$:
[cite_start]$$O^{t} = H(u^{t} - u_{th})$$ [cite: 1285]

### **2. Sparse Connection Routing**
[cite_start]To prevent parameter explosion when increasing the number of branches $D$, the network restricts connections so that each branch only sees a sparse, non-overlapping subset of the inputs[cite: 1332, 1333]. 

* [cite_start]Divide the $M$ feedforward input channels equally into $D$ groups[cite: 1323, 1490].
* [cite_start]Divide the $N$ recurrent hidden channels equally into $D$ groups[cite: 1329].
* Branch $d$ is ONLY multiplied by its corresponding slice of inputs. [cite_start]Mathematically, the weight matrix $W$ is strictly block-diagonalized or masked so that the index set $P_d$ of connected inputs satisfies $P_d \cap P_j = \emptyset$[cite: 1323, 1326]. 

---

### **3. Network Architecture (Bidirectional)**
[cite_start]For the SSC task specifically, the model utilizes a **bidirectional DH-SRNN** architecture[cite: 1447].

* **Parallel Processing:** Construct two identical DH-SRNN layers for every hidden layer depth. [cite_start]One processes the temporal sequence forward ($t = 1 \dots T$), and the other processes it backward ($t = T \dots 1$)[cite: 1447].
* [cite_start]**Concatenation:** At each timestep, concatenate the spiking outputs of the forward layer and the backward layer[cite: 1448]. 
* [cite_start]**Stacking:** Pass this concatenated spike sequence as the feedforward input $X^{t}$ to the next bidirectional layer[cite: 1448].
* [cite_start]**Readout Layer:** The final layer is a non-spiking LIF layer (it accumulates membrane potential but does not generate spikes)[cite: 1434].
    [cite_start]$$u_{out}^t = \beta_{out} u_{out}^{t-1} + (1-\beta_{out}) W_{out} O_{last\_hidden}^t$$ [cite: 1434]
    The final classification probability is generated by summing the membrane potentials over all timesteps and applying a softmax:
    [cite_start]$$\hat{y} = \text{softmax}\left(\sum_{t=1}^{T} u_{out}^t\right)$$ [cite: 1434]

### **4. Backpropagation and Surrogate Gradient**
[cite_start]Because the Heaviside step function $H(\cdot)$ is non-differentiable, you must implement a custom surrogate gradient for the backward pass to enable BPTT[cite: 1371, 1372]. 

[cite_start]The paper uses a specific **Multi-Gaussian Surrogate Gradient** centered around the threshold[cite: 1372, 1375]:
[cite_start]$$H'(u^t) = \gamma(1+h)\mathcal{N}(u^t|u_{th}, \sigma^2) - \gamma h \mathcal{N}(u^t|\sigma, (s\sigma)^2) - \gamma h \mathcal{N}(u^t|-\sigma, (s\sigma)^2)$$ [cite: 1373]
*(Note: $\mathcal{N}(x|\mu, \sigma^2)$ represents the Gaussian probability density function).*

[cite_start]**Hyperparameters for SSC**[cite: 1435, 1438]:
* $\gamma = 0.5$
* $h = 0.15$
* $\sigma = 0.5$
* $s = 6$
* [cite_start]**Optimizer**: Adam with an initial learning rate of $10^{-2}$ and a step learning rate scheduler[cite: 1438].
* [cite_start]**Loss Function**: Cross-Entropy Loss ($L = -\sum y_i \log \hat{y}_i$)[cite: 1437].

### **5. Replicating Figure 5f (SSC Heatmap)**
To generate the exact data grid shown in Figure 5f, you will need to set up the data and run a nested loop over the architectural hyper-parameters.

**Data Preparation:**
* [cite_start]The raw Google Speech Command audio is converted to spikes using a bionic inner ear model[cite: 1352]. 
* [cite_start]Sample the data at $dt = 1ms$[cite: 1363]. 
* [cite_start]The resulting input dimension is a binary matrix of $700 \text{ channels} \times T \text{ timesteps}$[cite: 1363].

**Grid Search Dimensions:**
You must train separate models for every combination of the following two variables, extracting the peak testing accuracy for each run:
* [cite_start]**Number of Hidden Layers**: 1, 2, 3, 4, and 5 layers[cite: 840, 854, 874].
* [cite_start]**Number of Dendritic Branches ($D$)**: 1, 2, 4, and 8 branches[cite: 885]. 
* [cite_start]**Baseline (Vanilla)**: For the "Vanilla" column in the heatmap, set $D=1$ and disable the dendritic current logic (equation 3), feeding inputs directly to the soma[cite: 283, 284].
